서비스 제공 관점에서 다음 작업을 우선순위별로 정리했습니다.

공통

  • 공개 저장소 전반에 Dependabot, 기본 보안 스캔, 릴리스 체크리스트를 붙입니다.
  • README, Pages, wiki, 루트 허브 설명 문구를 같은 서비스 언어로 맞춥니다.
  • 주요 서비스형 저장소에는 CHANGELOG, 버전 태그, 운영 문서, 장애 대응 문서를 둡니다.
  • 페이지와 문서에서 바로 이어지는 설치, 사용, 피드백 경로를 만듭니다.

AI_BISEO

  • 운영용 키와 자동화용 키를 분리하고 로그에 민감 정보가 섞이지 않게 정리합니다.
  • 프로젝트 버전별 결과 비교와 실패 원인 기록 화면을 강화합니다.
  • 자동화 실패 시 Telegram이나 Discord 알림을 붙입니다.

AI_Writer_TISTORY

  • 초안 생성과 실제 발행 사이에 승인 단계를 둡니다.
  • 중복 문장, 제목, 설명, 링크 구조를 체크하는 SEO 검수 로직을 추가합니다.
  • 티스토리 API 실패와 rate limit을 운영자가 읽기 쉽게 정리합니다.

  • 일별 손익 외에 전략별 성과 비교와 손실 경보를 만듭니다.
  • 백테스트, 실거래, 리포트 흐름이 한 화면에서 이어지도록 정리합니다.

BloggerGent

  • 운영자가 빠르게 검수할 수 있는 발행 QA 체크리스트를 만듭니다.

  • S~F 등급 근거를 설명형 리포트로 바꾸고 공유 링크를 제공합니다.
